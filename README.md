# 💈 Barber Shop Website

A modern and responsive barber shop website built to showcase grooming services, haircut styles, and business information. The website provides customers with an easy way to explore services, view the gallery, and contact the barber shop for appointments.

## ✨ Features

- 🏠 **Home Page** – Attractive landing page introducing the barber shop.
- ✂️ **Our Services** – Displays haircuts, fades, beard trims, and grooming services.
- 🖼️ **Gallery** – Showcases haircut styles and barbering work.
- 📅 **Appointments** – Helps customers request or schedule bookings.
- 📍 **Contact Information** – Displays location and contact details.
- 📱 **Responsive Design** – Works across mobile phones, tablets, and desktops.
- 🎨 **Modern UI** – Clean layout with a stylish barber shop aesthetic.
